# ギルドバトルのゲーム仕様

対象は『メメントモリ』のギルドバトル。公式ヘルプの記載と、プレイ上確認された具体的な条件を区別して記録する。

## パーティの新規配置

進攻・防衛ともに、少なくともW107までは以下の人数で1パーティを配置できる（ユーザー確認）。

| 拠点種別 | 拠点名 | 配置可能人数 |
| --- | --- | --- |
| 神殿 | ブラッセル／アイン | 3・4・5体 |
| 城 | ブラッセル、ウィスケルケー、モダーヴ、シメイ、グラベンスティン／アイン、イエソド、デファレト、マルクト、ケテル | 3・4・5体 |
| 教会 | 上記以外の拠点 | 2・3・4・5体 |

公式ヘルプによると、最低配置人数は拠点種別によって異なり、ワールドの開設期間に応じて増加する。W108以降の配置人数と、開設期間による変更の境界は未確認。

「ブラッセル」と「アイン」は神殿と城の両方に記載されている。拠点の記録には名前と種別を併記する。

## 戦闘と連戦

| 項目 | 仕様 | 根拠 |
| --- | --- | --- |
| 戦闘の進行 | 戦闘は自動で行われ、戦闘が続いている間は1秒に1戦進む。 | ユーザー確認 |
| 1戦の結果 | 進攻・防衛の一方が勝利し、他方が敗北する。引き分けはない。 | ユーザー確認 |
| HPの引き継ぎ | 勝利側は生き残ったキャラで連戦し、戦闘終了時のHPを次戦に引き継ぐ。 | 公式ヘルプ |
| 残存人数とKO | 配置後は戦闘で残存人数が減る。勝ち残った1体が次戦で倒された場合、その戦闘で敗北側が失った人数は1体（被KOは1）。 | ユーザー確認 |
